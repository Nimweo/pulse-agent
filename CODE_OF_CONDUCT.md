# Code of Conduct

## Our standard

Pulse Agent contributors and maintainers are expected to be welcoming,
respectful, constructive, and professional. Harassment, discrimination,
personal attacks, intimidation, doxxing, and deliberate disruption are not
acceptable.

## Scope

This code applies in project spaces, including issues, pull requests,
discussions, reviews, and community communication related to Pulse Agent.

## Enforcement

Report unacceptable behavior privately to the repository maintainers through
the contact options on the GitHub organization profile. Do not create a public
issue for sensitive reports. Reports will be reviewed fairly and handled as
confidentially as practical.

Maintainers may remove comments, close discussions, reject contributions, or
restrict participation when necessary to protect the community.

## Attribution

This policy is inspired by the Contributor Covenant and may be adapted as the
project community grows.
